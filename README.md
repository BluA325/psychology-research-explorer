# 心理学文献探索器

输入一个心理学的研究问题或专业名词，自动定位相关文献、按研究方向归类，并找出该领域"还可以研究什么"。

打开 `index.html` 即可使用，无需安装任何东西。

## 它做什么

1. **定位文献**：中文问题会自动翻译成国际文献库的检索词。例如「青少年社交焦虑的干预」→ `social anxiety adolescents intervention`。每篇文献都提供原文 DOI、OpenAlex、知网、谷歌学术、百度学术、PubMed 的跳转链接，开放获取的直接给免费全文。

2. **按研究方向归类**：依据文献数据库的学科主题自动分组，每个方向给出文献量、近三年占比、篇均被引、年度趋势、代表作、主要期刊和高频关键词。支持按年份、被引数、是否开放获取、是否只看综述筛选，结果可导出 Excel（CSV）、BibTeX、EndNote（RIS）。

3. **找出还能研究什么**：结合四条证据线生成选题清单——
   - 从摘要中抽取作者亲笔写下的「未来研究应……」「仍不清楚」原句，并标注出处
   - 主题共现分析，找出「各自成熟、交叉稀疏」的组合
   - 方法结构对比（综述多而随机对照试验少 → 干预证据缺口；横断面多而纵向设计少 → 因果设计缺口）
   - 样本人群分布（中国样本、老年人、临床样本占比低 → 换人群即增量）

   每条空白都给出对应数字，并生成可直接上手的研究问题，附「为什么值得做」「建议研究设计」「点击即搜的检索关键词」。

## 数据来源

- [OpenAlex](https://openalex.org/)（主，2.5 亿+ 学术记录，开放数据）
- [Crossref](https://www.crossref.org/)（备，1.5 亿+ 记录）

两个数据源都支持浏览器直接调用，因此本工具是纯前端单文件程序，不需要服务器、不需要 API Key。

## 分享链接

检索之后，地址栏会变成 `index.html?q=认知失调` 的形式。把这个链接发给别人，对方打开时会自动执行同一次检索，直接看到相同的结果页面。

## 隐私

所有收藏都保存在浏览器本地（localStorage），不会上传到任何服务器。

## 免责说明

研究方向归类、研究空白挖掘与选题建议由**文献计量统计 + 摘要文本挖掘**自动生成，属于选题线索而非评审意见。正式选题前请点开原文核对，尤其确认最近 1–2 年的新文献是否已经填补了该空白。

## 本地运行

直接用浏览器打开 `index.html` 即可。如果浏览器限制了本地文件联网，可以在该目录下起一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。
